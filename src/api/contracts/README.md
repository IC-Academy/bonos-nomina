# Contratos API (PROPUESTA)

Interfaces TypeScript que describen lo que cada módulo del frontend necesita.
**No son endpoints productivos**: no fijan rutas, verbos ni tecnología. El equipo
de backend (SharePoint / Power Automate / n8n / Fabric) decidirá cómo se
exponen y el adaptador productivo implementará estas interfaces.

Detalle por módulo y fuentes probables: `docs/contrato-api-frontend.md`.
